立ち絵を置くフォルダです。

【置き方】
1. このフォルダに画像ファイルをアップロードする（ファイル名は自由。例: ho1.png, ho1_modal.png など）
2. assets/js/characters.js の CHAR_DATA の該当キーに、置いたファイルへのパスを書く

例）HO1の立ち絵を追加する場合：
  ho1: {
    ...
    cardArt:  'assets/tachie/ho1.png',        ← 探索者一覧のカードを裏返した時に出る絵
    modalArt: 'assets/tachie/ho1_modal.png',  ← カードをクリックした時のモーダルに出る絵
  }

cardArt と modalArt は別々の画像を指定できます（同じファイルを両方に指定してもOK）。
NPC（菅原・小野道・岡田）は modalArt のみ使います（一覧カードに裏返しはないため）。

空欄のままにしておけば、これまで通り仮のシルエットが表示されます。
画像を用意していないキャラだけ空欄のままでも問題ありません。
